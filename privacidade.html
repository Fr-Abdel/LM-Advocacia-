Esta página descreve o funcionamento desta beta. Não é uma política pronta para uso por um escritório real.

1. O que este site é

LM Advocacia é um projeto fictício de portfólio. Não representa um escritório em operação, não oferece consulta jurídica e não disponibiliza canais reais de atendimento.

2. O formulário

O formulário usa JavaScript no navegador para verificar o preenchimento e gerar uma prévia. Não há servidor de formulários, API, e-mail ou integração com WhatsApp.

Os valores ficam nos elementos da página enquanto ela está aberta. O código não grava essas informações em cookies, localStorage, sessionStorage ou bancos de dados. O botão “Limpar e recomeçar” limpa os campos e a prévia.

O navegador pode restaurar campos ao navegar ou reabrir páginas, conforme suas próprias configurações. Por isso, use apenas exemplos fictícios. A opção de copiar a prévia só escreve na área de transferência após um clique explícito.

3. Recursos e hospedagem

As fontes são do sistema e os recursos visuais são locais. O projeto não inclui analytics, rastreadores, mapas incorporados ou fontes externas.

O provedor de hospedagem poderá processar dados técnicos de acesso, como endereço IP e registros de requisições, conforme sua própria política. O link para o GitHub abre um serviço externo, sujeito às regras daquele serviço.

4. Antes de um uso real

Substituir o conteúdo fictício exige definir o responsável pelo site, a finalidade e o tratamento dos dados, os canais de contato e as condições do provedor escolhido. Uma operação real demanda revisão jurídica e configuração técnica próprias.
