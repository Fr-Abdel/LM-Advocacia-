Este escritório existe?

Não. A LM Advocacia é uma marca fictícia criada exclusivamente para demonstrar um projeto de desenvolvimento web.

O site oferece orientação jurídica?

Não. O conteúdo descreve um conceito institucional e não analisa situações concretas. A demonstração não presta serviços jurídicos.

O que acontece ao preencher o contato?

O site valida os campos e apresenta uma prévia local da mensagem. Nada é enviado ou salvo pelo formulário. Use somente dados fictícios.

Preciso anexar documentos?

Não. A beta não aceita arquivos. Evite inserir documentos, números de processo ou relatos sensíveis no campo de mensagem.
